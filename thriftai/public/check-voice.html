💡 Setup Instructions

Option 1: Use Browser Voices (Free, works now)
The app will automatically select the best American voice from your browser.

Option 2: Setup Google Cloud TTS (Best quality)
1. Get API key: console.cloud.google.com
2. Add to .env.local: GOOGLE_CLOUD_TTS_API_KEY=your_key
3. Restart server: npm run dev
