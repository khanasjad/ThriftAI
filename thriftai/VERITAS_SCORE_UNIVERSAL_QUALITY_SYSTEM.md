## 🎯 How Veritas Score Adapts Across Conditions

### 1. Product Quality Category (25% Weight)

**For NEW Products:**
```
Focus Areas:
✓ Authenticity verification (100% weight on genuine)
✓ Packaging condition (sealed = 100)
✓ Manufacturing date (recent = higher score)
✓ Batch/serial verification
✓ Warranty coverage
✓ Defect rate of product line

Parameters Heavily Weighted:
- Authenticity: 15%
- Packaging Integrity: 12%
- Manufacturing Date: 10%
- Warranty Coverage: 8%
```

**For REFURBISHED Products:**
```
Focus Areas:
✓ Refurbisher certification level
✓ Parts replacement quality (OEM vs. generic)
✓ Testing procedures performed
✓ Warranty offered
✓ Cosmetic restoration quality
✓ Battery/component health (electronics)

Parameters Heavily Weighted:
- Refurbisher Certification: 15%
- OEM Parts Usage: 12%
- Testing Certification: 10%
- Warranty Duration: 8%
```

**For USED Products:**
```
Focus Areas:
✓ Actual condition vs. description
✓ Wear and tear assessment
✓ Functional completeness
✓ Missing components
✓ Age/usage hours
✓ Remaining lifespan

Parameters Heavily Weighted:
- Condition Accuracy: 15%
- Functional Testing: 12%
- Wear Assessment: 10%
- Component Completeness: 8%
```

### 2. Seller Trust Category (20% Weight)

**Adapts to Seller Type:**

**Authorized Dealer (New Products):**
```
Parameters:
- Manufacturer Authorization: 20%
- Return Policy: 15%
- Official Warranty: 15%
- Business License: 10%

Baseline Score: 85/100 (authorized status)
```

**Certified Refurbisher:**
```
Parameters:
- Refurbisher Certification: 20%
- Refurbishment Process Transparency: 15%
- Quality Guarantee: 15%
- Return Window: 10%

Baseline Score: 80/100 (certified status)
```

**Individual Seller (Used):**
```
Parameters:
- Seller Rating: 15%
- Transaction Count: 12%
- Response Time: 10%
- Honest Description History: 10%

Baseline Score: Variable (0-100 based on history)
```

### 3. Market Value Category (15% Weight)

**For NEW Products:**
```
Reference Price: Manufacturer MSRP
Calculation: How much BELOW MSRP

Example:
MSRP: $1000
Listed: $800 (20% off)
Score: 70/100

If listed at $900 (10% off): 60/100
If listed at $600 (40% off): 85/100
```

**For REFURBISHED Products:**
```
Reference Price: New product price - Expected depreciation
Calculation: Value vs. comparable refurbs

Example:
New: $1000
Expected Refurb: $650 (35% depreciation)
Listed: $600
Score: 85/100 (better than expected)
```

**For USED Products:**
```
Reference Price: Age-adjusted market average
Calculation: Value vs. similar condition items

Example:
New: $1000
2-year-old, Good condition average: $400
Listed: $350
Score: 90/100 (great deal)
```

### 4. Sustainability Category (12% Weight)

**Score Boost by Condition:**

```
NEW Product:
Base Score: 40/100
(Encourages buying refurb/used instead)

Exceptions: Sustainable/Eco-Certified New
Score: 80/100

REFURBISHED:
Base Score: 85/100
(Professional restoration = high sustainability)
Bonus for certified refurbisher: +10

USED:
Base Score: 90/100
(Maximum sustainability impact)
Bonus for local pickup: +5

Calculation:
Carbon Footprint Saved = (1 - Condition_Factor) × New_Product_Footprint

Condition Factors:
- New: 0%
- Refurbished: 60%
- Used: 80%
```

### 5. Product Specification Category (13% Weight)

**Condition-Specific Adjustments:**

**NEW:**
```
Baseline: 100% if all specs match manufacturer claims
Penalties:
- Missing original accessories: -15
- Older model year: -10
- Discontinued model: -5
```

**REFURBISHED:**
```
Baseline: 90% (refurbished by nature has some history)
Bonuses:
- OEM parts: +10
- Upgraded components: +15
- Extended warranty: +10
```

**USED:**
```
Baseline: Variable based on completeness
Scoring:
- All original parts: 90/100
- Missing minor accessories: 75/100
- Missing major components: 50/100
- Modified/upgraded: Contextual (may increase or decrease)
```

## 💡 New vs. Used vs. Refurbished Strategy

### Decision Framework for Buyers

**When to Buy NEW:**
```
✅ Latest tech/features required
✅ Full warranty essential
✅ Gift for someone special
✅ Business/professional use (tax write-off)
✅ Minimal price difference vs. refurb

Expected Veritas Score: 75-85/100
(Lower due to full price, but peace of mind)
```

**When to Buy REFURBISHED:**
```
✅ Want warranty + savings (best of both)
✅ Recent model is fine (not cutting-edge needed)
✅ Certified/reputable refurbisher available
✅ Electronics (high-quality refurbs available)
✅ 30-50% savings target

Expected Veritas Score: 85-95/100 ⭐
(Often HIGHEST scores due to quality + value + sustainability)
```

**When to Buy USED:**
```
✅ Budget-conscious
✅ Product is durable/timeless
✅ Okay with no warranty
✅ Vintage/collectible items
✅ Maximum sustainability impact

Expected Veritas Score: 70-90/100
(High variance based on condition and seller)
```

### The "Refurbished Premium" Phenomenon

**Data shows certified refurbished often scores HIGHER than new:**

```
Why Refurbished Wins:

1. Quality Control:
   - Tested twice (manufacture + refurbish)
   - Defects caught and fixed
   - Often more reliable than new

2. Value:
   - 30-50% savings
   - Similar/same warranty
   - Market Value score boost

3. Sustainability:
   - Major environmental benefit
   - Appeals to eco-conscious buyers
   - Circular economy contribution

4. Selection:
   - Older models still available
   - Sometimes upgraded components
   - Better price/performance ratio

Result:
New iPhone: 82/100
Certified Refurb iPhone: 89/100 ✅
```

## 🎯 Category-Specific Scoring Adjustments

### Electronics

**NEW:**
- Emphasize: Latest specs, warranty, defect rate
- De-emphasize: Sustainability (new production penalty)
- Expected: 75-85/100

**REFURBISHED:**
- Emphasize: Refurbisher certification, OEM parts, warranty
- Bonus: Battery replacement (for phones/laptops)
- Expected: 85-95/100

**USED:**
- Emphasize: Battery health, screen condition, functional testing
- Critical: Hours of use (if available)
- Expected: 60-90/100

### Fashion/Apparel

**NEW:**
- Emphasize: Authenticity, current season, tags attached
- De-emphasize: Market value (fashion depreciates)
- Expected: 70-85/100

**CONSIGNMENT/USED:**
- Emphasize: Authenticity verification, designer brand
- Bonus: Vintage/rare items
- Expected: 65-90/100

### Furniture

**NEW:**
- Emphasize: Materials quality, assembly difficulty
- Neutral: Sustainability (new wood vs. reuse debate)
- Expected: 70-85/100

**USED:**
- Emphasize: Solid wood (ages well) vs. particle board
- Critical: Structural integrity, smell, stains
- Expected: 50-85/100

### Automotive

**NEW:**
- Emphasize: Warranty, dealership reputation, model year
- Expected: 75-90/100

**CERTIFIED PRE-OWNED:**
- Emphasize: Manufacturer certification, mileage, inspection
- Expected: 80-92/100 (often beats new on value)

**USED:**
- Emphasize: Maintenance records, CarFax, mechanical inspection
