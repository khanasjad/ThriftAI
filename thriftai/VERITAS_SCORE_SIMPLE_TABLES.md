## Key Formulas

### 1. Category Score
```
Category Score = Σ(Parameter Score × Parameter Weight) / Total Parameter Weight
```

### 2. Overall Score
```
Overall Score = Σ(Category Score × Category Weight)
```

### 3. Value Index
```
Value Index = (Overall Score / Price in dollars) × 100

Higher = Better value
```

### 4. Confidence
```
Confidence = Average of all category confidence levels
```

### 5. SSN (Score Serial Number)
```
Format: VS-{CATEGORY}-{SCORE}-{CONF}-{DATE}

Example: VS-ELE-089-92-20251003
         ↑   ↑    ↑    ↑    ↑
         |   |    |    |    └─ Date (2025-10-03)
         |   |    |    └────── Confidence (92%)
         |   |    └─────────── Score (89/100)
         |   └──────────────── Category (Electronics)
         └──────────────────── Veritas Score
```
