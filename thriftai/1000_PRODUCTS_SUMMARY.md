
### Search Products (via API)
```bash
# Search for specific category
GET /api/buyers/enhanced-search
Body: { "query": "Nike shoes", "pagination": { "page": 1, "limit": 20 } }

# Filter by price
GET /api/buyers/enhanced-search
Body: { "query": "laptops under 1000", "pagination": { "page": 1, "limit": 20 } }

# Find trending products
GET /api/buyers/enhanced-search
Body: { "query": "", "sorting": { "field": "trending", "direction": "desc" } }
```

### Query Examples
```typescript
// Get top 10 most popular products
const popular = await prisma.product.findMany({
  where: { isAvailable: true },
  orderBy: { popularityScore: 'desc' },
  take: 10
})

// Get products with free shipping under $100
const deals = await prisma.product.findMany({
  where: {
    hasFreeShipping: true,
    price: { lte: 100 },
    isAvailable: true
  }
})

// Get low stock products
const lowStock = await prisma.product.findMany({
  where: {
    stockQuantity: { lte: 5 },
    isAvailable: true
  }
})

// Get products with reviews
const reviewed = await prisma.product.findMany({
  where: {
    reviews: { some: {} }
  },
  include: {
    reviews: true
  }
})
```
